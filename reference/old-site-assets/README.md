# old-site-assets — Previous RWHC Website Materials

Drop assets from the old Redwood Hotel Casino website here.

## What belongs here

- Screenshots of old homepage and any interior pages
- Any photography used on the old site (hero images, room photos, casino floor, restaurant)
- Old logo files (any format)
- Any existing brand color or font references from the old site
- Old menu PDFs, brochure scans, print materials
- Screenshots of any promotional graphics or event materials

## How these will be used

These assets are reference only — they show what existed before, what photography is available, and what brand elements (if any) are worth carrying forward. They won't be committed to the production build directly.

## Naming convention

Use descriptive names:
- `old-site-homepage.png`
- `old-site-logo.png`
- `casino-floor-photo.jpg`
- `hotel-room-exterior.jpg`
- `abalone-bar-interior.jpg`
