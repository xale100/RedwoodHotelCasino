# /reference — Visual Ground Truth

Drop mood board images, screenshots, and reference assets here before build begins.

This directory is the visual ground truth. Files here inform every design decision.
Nothing in `/reference` is committed to production builds.

## What to drop here

- Screenshots of any of the 11 reference sites (especially Post Ranch Inn dark-green sections, Visit Yurok Country amber CTAs)
- Photographs of the actual Redwood Hotel Casino property (exterior, casino floor, hotel rooms, restaurant)
- Any official Yurok Tribe brand materials (seal, approved photography, color palette documents)
- Inspiration images for the hero section (Klamath River, old-growth canopy, coastal fog, salmon)
- Any existing RHC marketing materials (brochures, social posts, signage)

## Format

Name files descriptively: `pechanga-gold-cta-button.png`, `klamath-river-hero-ref.jpg`, `yurok-seal-official.svg`
